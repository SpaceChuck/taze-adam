# Taze Adam Launch Arguments
--noquitbutton: Disables the quit button

--brokenquitbutton: Makes the quit button disappear when pressed

--forcefullscreen: Forces the game to fullscreen, disabling the toggle in the options

--forcewindowed: Forces the game to windowed, disabling the toggle in the options

--nomenu: Replaces menu buttons with quit buttons in the game

--playcustomlevel <level.json>: Opens the selected level in play mode

--editcustomlevel <level.json>: Opens the selected level in edit mode

--playlevel <1,2,3,-101>: Plays one of the built-in levels

--debugmode: Enables debug mode

--language <English/Turkish>: Sets the game language, disabling the dropdown

--customlanguage <language.json>: Loads a custom JSON file as the game's language

--noupdatecheck: Disables the update check

--defaultcontrolmode <Keyboard/Touch>: Changes the default control mode

--forcetouchcontrols: Forces touch controls

--devconsole: Enables the developer console
