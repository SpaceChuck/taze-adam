Taze Adam 2.2.2 Güncellemesi

Taze Adam v2.2.2 has been released!

This update adds Level Repositories, a way to share your levels with other players. If you want to learn how, this GitHub repo will help.

Changelog:

- Added Level Repositories

- Updated the UI (the trees no longer float)

- Updated the Taze Adam Logo

- Changed the format of saved levels

  This also fixes saving of rotated trampolines

  They show the name of the author below the level name, which can be changed in the options

  Old levels will still work and they will be updated when saved

- Added a UI scale slider to the options

- The dropdowns in the level editor are now translated

- Language files are now stored in StreamingAssets and can be modified

- Added a new cursor for dragging in the editor

- The Open Level Directory button now appears and works on macOS

- Added numbers for sliders

- The More Games menu now loads the games from the Taze Adam website, and is always up to date

- Improved update menu

Publish date: 7 September 2025
