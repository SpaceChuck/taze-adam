2.2.1 Update

Taze Adam v2.2.1 has been released on Windows, macOS and Linux! Android and WebGL might™ be Coming Soon™

App Store and Google Play releases are Not Coming™


v2.2.1 also updates the game  to Unity 6 which means the Made with Unity logo will no longer appear on startup. Unity 6 also increases the system requirements for the game, which means the game will now requires Windows 10 21H1, macOS 11, Ubuntu 22.04/24.04, iOS 13 and Android 6.0. Despite these ridiculous system requirements, the game still runs on Windows 32-Bit somehow. That's good news for all the 15 Windows 10 32-Bit users out there.

Thanks to Unity 6, this update also features a Windows ARM build. I honestly have no idea if it works or not, I don't have any devices to test it. The installer also isn't supported on Windows ARM. 

I hope this was good enough to make up for the lack of Windows 7 support.


Here is the update changelog:

- The level string in the editor is now an Input Field, and can be edited.

  Editing it will change where the level is saved.

  You can also enable "Show Full Level Path" in the options to make this show the full path to the level.

- Transitions within the menus are now faster, and will not restart the music.

- The Level Select and Options menus have been redesigned with a new tabbed UI.

- Added consistent select and highlight colors for all the UI.

- The editor toggles are now available in the Options menu, in their own "Editor" tab

- Controller support has (hopefully) been fixed thanks to Unity's new Input System.

- Menu navigation with arrow keys and controllers has been fixed.

  Pressing PgUp, PgDown/L1,R1 will change the menu tab.

- Controller tooltips are now more consistent.

- Added a new loading screen when transitioning between the menu and game.

- Added launch arguments to the game when launching it from the command-line.

  See https://spacechuck.github.io/taze-adam/other/tazeadamargs.html for more information.
