# Taze Adam v1.0 3rd Anniversary Edition
Introducing... (drum roll) 

Taze Adam v1.0 for Windows and Linux!

The original release of v1.0 only supported macOS and WebGL, and I couldn't just build for Windows and Linux as the project files for this release are gone, but using some super cool magical methods (i literally just copied some files from the macOS build of v1.0 to the Windows and Linux build of v1.1 and it somehow worked) I was able to port this old release to Windows and Linux!

So what's so special about this version anyway?

Well...





It's literally the same as v1.1 but it cuts off at the 5th checkpoint of Level 1. That's it.
